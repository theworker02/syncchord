# syncchord

Sync CSV/TSV chord tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/syncchord/

## Install / run

```bash
git clone https://github.com/theworker02/syncchord.git
cd syncchord
node src/cli.js
node --test
```
